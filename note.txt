PROJECT CONTEXT
You are NOT building a simple crafting page.
You are building the official Project Zero Crafting Database.
The goal is to create a professional interactive crafting encyclopedia similar to modern game databases, not a CRUD website.
Everything must be driven by the database.
Never hardcode recipes.
Never hardcode stations.
Never hardcode materials.
The JSON/database is always the single source of truth.
==========================================================
PROJECT PHILOSOPHY
A player should be able to understand an entire crafting chain in one screen.
The player should never need to open 10 different pages just to understand how one item is crafted.
Everything should feel like an interactive blueprint system.
The application should feel closer to a game interface than a normal website.

BLUEPRINT WORKSPACE
The blueprint is the MOST IMPORTANT part of the application.
The blueprint is NOT a list.
It is a visual dependency graph.
Every recipe is displayed as a crafting tree.
Example
Iron Axe
↓
Iron Ingot
↓
Iron Ore
Coal
Wood Handle
↓
Wood
Rope
↓
Fiber
Knife
↓
Stone
The tree continues automatically.
Unlimited recursion depth.
==========================================================
RECURSIVE RULES
If a material has its own recipe
Automatically expand it.
If that recipe contains craftable materials
Expand again.
Continue recursively until reaching raw materials.
Never require manual expansion.
Everything must be generated automatically.
==========================================================
RAW MATERIAL
A raw material is an item without any recipe.
When no recipe exists
Stop recursion.
Display the raw material as the final leaf node.
==========================================================
LOOP PROTECTION
Prevent
A -> B -> C -> A
using
Visited Set.
Never allow infinite recursion.
Never duplicate recipes inside one branch.
==========================================================
TREE LAYOUT
The blueprint must always look clean.
Requirements
- parent centered above children
- equal spacing
- no overlapping nodes
- unlimited depth
- automatic subtree sizing
- professional tree layout
Do not use hardcoded margins.
